# RazerLite

Небольшая фоновая замена Synapse для **Razer Basilisk V3 (1532:0099)** и **Razer Cynosa Lite (1532:023f)** на Windows.

- Нижняя кнопка за колесом: короткое нажатие выбирает следующий цвет, удержание плавно меняет оттенок, отпускание сохраняет выбор на мыши и клавиатуре.
- Верхняя кнопка сохраняет переключение режима прокрутки.
- DPI мыши поддерживается на 26 000; выбор цвета не переключает чувствительность.
- Обе клавиши Windows блокируются в указанных играх или при активном полноэкранном приложении.
- Автозапуск службы и помощника без окон. Аккаунт и интернет для работы не нужны.

## Установка

Нужны Windows 10/11 x64 и **64-битный Python 3.10+ для всех пользователей**. Проверка на оборудовании выполнена с Python 3.14. Python должен быть доступен системной службе; пользовательская установка Microsoft Store для этого не подходит.

Скачайте и распакуйте `RazerLite-0.1.0-windows-source.zip` из [релизов](https://github.com/ZombiePm/RazerLite/releases). Откройте PowerShell от администратора из своей обычной учётной записи, перейдите в распакованную папку и выполните, указав свой путь к Python:

```powershell
.\install.ps1 -PythonPath 'C:\Python314\python.exe' -CheckOnly
.\install.ps1 -PythonPath 'C:\Python314\python.exe'
```

Если Windows блокирует загруженные сценарии, после просмотра их содержимого выполните `Unblock-File .\*.ps1`. Установка пакетов через pip не нужна. Это релиз с исходниками, не самостоятельный EXE.

Установщик копирует программу в `C:\Program Files\RazerLite`, создаёт службу `RazerLite` и задачу входа `RazerLiteSession`. **Службы Razer/Chroma, соответствующие задачи и записи автозапуска текущего пользователя сохраняются в резервную копию и отключаются**, чтобы программы не перезаписывали настройки друг друга. Приложения и драйверы Razer не удаляются. Для возврата к Synapse предусмотрен откат.

## Управление

Короткое нажатие нижней кнопки выбирает следующий цвет. После 350 мс удержания начинается плавный переход; соседние цвета сменяются за 1,4 секунды. Отпускание фиксирует оттенок. Палитра: зелёный, голубой, синий, фиолетовый, красный, жёлтый, белый.

В `C:\Program Files\RazerLite\config.json` можно задать DPI, яркость, режим блокировки Windows и список exe игр. Настройки перечитываются автоматически. `mode=fullscreen` использует полноэкранность, `mode=games` — список `games`, `mode=always` блокирует Windows постоянно. Браузеры, Explorer, видеоплееры, mstsc и Windows Terminal исключены по умолчанию. Полноэкранность не всегда означает игру; для оконных игр укажите exe явно.

Кнопка использует служебную клавишу F24, которую помощник перехватывает, в том числе с других клавиатур. Без помощника кнопка выдаёт F24. Отключение `color_button` в конфигурации само по себе не возвращает аппаратное назначение кнопки — для этого нужен сценарий отката.

Цвет и резервные копии хранятся в `C:\ProgramData\RazerLite`. До входа пользователя работает служба подсветки/DPI; обработка кнопки и клавиш Windows требует пользовательского сеанса.

## Откат

Подключите мышь и выполните в административном PowerShell под той же учётной записью:

```powershell
& 'C:\Program Files\RazerLite\restore.ps1'
```

Восстановятся назначения кнопки и автозапуск Razer; служба и задача RazerLite будут удалены. Для открытия интерфейса Razer заново войдите в Windows. Файлы и резервные копии остаются. Перед повторной установкой сначала выполните откат, чтобы сохранить исходные настройки.

## Проверки и ограничения

В проверенной конфигурации задержка программной цепочки до подтверждения HID-команды составила 22–24 мс в среднем по медиане, максимум около 40 мс. Это не измерение физической задержки светодиодов. Суммарное потребление памяти в простое — примерно 50 МБ; на другом ПК результаты могут отличаться. Пользователь подтвердил улучшение отклика.

Поддерживаются только указанные две модели; Basilisk V3 Pro/35K в этот релиз не входят. Перезагрузка и физическое переподключение отдельно не проверялись. Обратное чтение общей яркости мыши недоступно на проверенной прошивке. Работа с античитами не заявляется.

Тесты: `python -m unittest test_color_cycle test_mouse_binding`. Подробности измерений, диагностических сценариев и архитектуры — в [английской инструкции](README.md).
